Adds an editor tab for Office Open XML documents (docx, xlsx, pptx) uploaded in multipart requests, so you can edit the XML inside the document directly in the request. It is aimed at testing for XML External Entity (XXE) vulnerabilities in applications that parse Office files.

Features

  • Edit the XML inside an uploaded Office document in place, with no need to regenerate and re-upload a file for each payload.
  • Iterate quickly on XXE payloads, including out-of-band tests with Burp Collaborator.
  • Automatically detects Office documents in multipart requests by Content-Type, with a fallback that searches the request body for embedded ZIP data.
  • Configurable Content-Types and target file inside the document, so you can edit any part of the package.
  • Edits are repacked into the document and sent with the request, ready to forward from Repeater or Proxy.

Usage

  1. Send or intercept a multipart POST request that uploads a docx, xlsx or pptx file.
  2. Open the Office Open XML Editor tab on the request.
  3. Edit the XML, for example to insert an XXE payload.
  4. Send the request.
